# 元枢 · 共生工作台

这是从“行业智能体”工程中抽离出的独立视觉 Demo，项目名为 `lianshan-symbiotic-workbench`。

本项目用于展示“元枢”共生工作台的界面、交互和动效，不包含正式后台 Agent、数据库、租户、计费、知识库或联网检索服务，也不替代正式产品。

## 本地运行

```bash
npm run dev
```

## 构建与检查

```bash
npm run build
npm run test:sites
```

视觉依据、交互约束和动效决策见 `AGENTS.md`、`MOTION_CHANGE_PLAN.md`、`MOTION_SHOWCASE_PLAN.md` 与 `design-qa.md`。
